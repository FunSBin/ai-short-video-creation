# 从创意开始与剧本交接

只有用户尚未提供剧本时才进入本分支；已有有效剧本则读取并继续，不能为了套工作流另写一套。

最小立项信息：题材与观众、主人公的目标／阻碍、世界规则、集数、预计集长、视觉风格、发布范围及明确禁区。可从用户已有材料推导的作为可见假设；关键剧情缺口需提问，同时继续独立工作。少集数项目不强制扩成数十集，也不自动增加付费墙。

产出项目概念、人物关系与规则、全剧因果链、分集事件和本次需要的分集剧本。每集至少有推动事件、可见行动、选择与后果；结尾钩子服务下集，不靠虚构承诺。人物认知、道具状态、时间天气和伏笔按集登记。

每场写时间地点、角色目标、阻碍、具体事件、可拍画面、准确对白、声音与首尾变化。动作量和对白决定时长预算；剧情估时与真实桌读／样片时长分别记录。神话或历史人物需要事实准确时按可靠来源研究，原创改编标清，不能把虚构设定当民俗事实。

需要商业短剧立项、长篇结构、剧本医生或连写时，按需读取随包的[Short-Drama Factory](../modules/short-drama-factory/SKILL.md)，保留其MIT署名。仅加载当前模式所需参考。其长篇规模、节拍、语速和政策资料不能压过本项目当前需求，也不是平台算法保证。

剧本阶段交接：有效源版本、分集／场号、人物和世界规则、道具状态、天气时间、准确台词、预计时长、待决剧情。用户已锁定的核心台词、形象和结局保护；技术细化在分镜阶段完成，不偷偷修改源稿。
