# 新项目配置和唯一入口

接手先读项目自己的规则、源稿、总入口、现用资产和用户最新反馈。本包仅提供通用制作方法，不携带上一位用户的个人偏好或收费授权。

新项目可采用以下简洁目录，已有项目沿用自己的结构：

```text
00_项目入口.md
project-settings.json
剧本/
资产/人物、场景、道具、关键帧、群体、特效、封面、归档
分镜/
提示词/
媒体/
剪辑/
交接/
```

资源图片只存唯一原件，分镜、提示词和上传清单引用原图路径，不复制进每个片段。相同哈希才可视为完全相同内容，其他版本各自保留与标状态。跨机器移交使用相对项目根目录的路径索引；实际提交时解析为当前机器存在的路径，不发布个人目录。

参考[项目设置模板](../templates/project-settings.example.json)。模型和画幅只是候选配置，第一次执行前按用户与真实入口确定；生成权限默认`manual`。记录本次允许的工作范围、已有禁止项和重试／数量边界。用户明确的历史授权持续有效，不为已授权可逆工作反复提问。

入口记录：源稿版本、当前阶段、唯一现用文档、资产台账、镜号／生成段／剪辑秒段映射、真实状态、用户通过范围、待修问题和下一动作。实际状态分开记设计完成、图已生成、自检、配置通过、视频已生成、音视频实测和用户通过；不能互相推导。

新增或换版只更新现用入口和调用者，历史结果保留。交接读取最新实际状态后再写，特别是用户自行点击生成的任务。凭据保存在宿主／平台认证中，不放项目设置或交接文档。
