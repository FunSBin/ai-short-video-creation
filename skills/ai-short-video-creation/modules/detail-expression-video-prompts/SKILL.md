# 细节表情生视频提示词

## 核心原则

把抽象情绪翻译成摄影机能看到、麦克风能听到、且前后存在因果的表演过程：

```text
触发事件 → 生理反应 → 眼神与面部变化 → 身体重心或互动 → 情绪余韵
```

“悲伤、震惊、决绝”只能作为设计标签，不能代替动作。生成模型对精确表演和秒点的服从是概率性的；提示词提高可控性，但不保证逐帧复现，参考图、模型和时长都会限制结果。

## 工作方式

1. 保留用户明确给出的模型、时长、参考素材、角色、台词、画幅与禁区。只有缺失信息会显著改变结果时才提问；其余做出简短、可见的假设。
2. 确定唯一的情绪主体、对手或触发源，以及摄影机为什么在这个位置。若用户要求另一人不抢戏，将其限制为失焦前景、背影、肩颈或画外声。
3. 先写心理阶段，再分配时间。按“察觉—消化—压住—越过临界点—行动或余韵”等真实转折切段，不机械平均分秒。
4. 每个阶段选择 2–5 个彼此兼容的可见变化。眼神单独设计：视线方向、聚焦状态、移动速度、停留位置、回避与重新对视。
5. 用嘴角、嘴唇、下颌、吞咽、鼻翼、呼吸、肩颈、手指和身体重心补全克制表演。动作必须从上一状态长出来，避免突然变脸、突然落泪或突然扑抱。
6. 有台词时绑定“说话前准备—关键词上的动作—停顿或抢入—说完后的反应”，不要让对白变成孤立朗诵。
7. 双人戏中，让 A 的台词或动作触发 B 的即时反应，再触发下一轮变化。只有存在剪辑或对白覆盖时才使用 reaction beat、J-cut/L-cut；只有空间关系复杂时才强调 180 度轴线、视线匹配与屏幕方向。
8. 强动作补充物理反馈链；环境和背景人物只做低强度响应。负面约束只针对本场最可能的失败，不堆砌无关禁词。
9. 输出可以直接复制到视频模型中的完整提示词，并以一句“连续性总约束”收束最重要的情绪链。

## 输出结构

按实际需要使用以下顺序；无关部分省略：

| 部分 | 必须回答的问题 |
|---|---|
| 场景与关系 | 发生在哪里，人物为何处于此刻，谁是表演主体 |
| 机位与构图 | 谁清晰、谁失焦、景别、轴线、镜头运动如何服务表演 |
| 光线与真实感 | 光源、皮肤和材质如何保持真人质感 |
| 情绪时间轴 | 每段的触发、眼神、口颌、呼吸身体、互动或台词 |
| 声音 | 环境声、呼吸、台词音色、抢话或停顿 |
| 负面约束 | 本场最可能出现的跳情绪、抢主体、夸张演技和连续性错误 |
| 连续性总约束 | 用一条箭头链重申起点、转折、临界点和结尾 |

完成成品提示词前，读取 [提示词结构与条件模块](references/prompt-contract.md)。需要校准成品颗粒度或参考写法时，读取 [完整示例](references/complete-example.md)。

## 快速示例

不要写：

> 她悲伤地看着男主，然后哭着抱住他。

改写为过程：

> 她先维持一个很浅但不稳定的笑，视线在男主脸上多停半秒；笑意缓慢消失，目光短暂下落后重新对视，下唇绷住，呼吸变浅。泪膜形成但暂不落下；她说完最后一句话后仍停留一拍，才向前靠近并收紧双臂。

## 常见错误

- 把文学词当动作：将“心碎、压住情绪、下定决心”继续翻译为可见变化。
- 每段塞入所有器官：只选推动当前转折的信号，避免面部动作互相打架。
- 用小数秒制造虚假精确：精确停留只用于关键反应拍，并视为节奏锚点而非逐帧保证。
- 双人各演各的：明确上一人的哪一句、哪个视线或动作触发下一人的变化。
- 镜头术语压过表演：焦段、浅景深和运镜必须解释其注意力作用，否则删掉。
- 负面词无限增长：只保留能防止本场高概率失败的约束。
