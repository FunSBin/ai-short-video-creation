# 提示词结构与条件模块

在交付成品视频提示词前使用本规范。先满足核心结构，再按单人、对白、双人或强动作场景增加条件模块。

## 一、输入判定

优先提取：

- 生成方式：文生视频、图生视频、首帧/尾帧、参考视频复刻或提示词改写。
- 模型与硬约束：模型、时长、画幅、镜头数、参考素材、角色一致性、口型或声音要求。
- 戏剧事实：人物关系、触发事件、情绪起点、临界点、结尾动作。
- 视觉主次：唯一清晰主体、对手的出现方式、环境可见程度。
- 表演强度：克制、明显但不失控、强烈；不要自行把“哭”解释为嚎哭。

用户要求“先设计确认”时，先交付场景、时长、情绪链、主体构图、台词和结尾动作六项设计，等待确认后再写成品。没有这一要求时直接完成。

## 二、核心成品合同

### 1. 场景与人物关系

用可见证据表达前情，避免长篇剧情解释。行李、冷掉的晚餐、未读消息、未动的饮料等道具可以承担叙事，但不能抢主体。

### 2. 机位与构图

说明：

- 摄影机站在哪一方，为什么能看到关键反应。
- 主体位置、景别、焦点和对手的可见范围。
- 是否连续镜头；若切镜，保持视线匹配、人物屏幕方向和动作连续。
- 运镜只在情绪或动作需要时出现。例如靠近人物可用极慢前推，拥抱进入画面可轻微后撤。

焦段数字是视觉意图的辅助，不是必须项。用户未要求专业参数时，优先写“中近景、浅景深、焦点锁定双眼”等可理解的结果。

### 3. 表演时间轴

每个阶段使用以下槽位：

```text
时间段｜心理阶段
触发：上一刻什么变化导致这一阶段。
眼神：方向、聚焦、速度、停留、回避/对视。
口颌：嘴角、嘴唇、下颌、吞咽、说话准备。
呼吸与身体：鼻翼、胸腔、肩颈、手指、重心、步伐。
互动/台词：对方如何触发，台词在哪个动作上发生。
余韵：本段结束时保留什么，如何进入下一段。
```

每段只保留推动转折的 2–5 个信号。动作顺序应可执行，不能同时要求互相冲突的状态。

### 4. 声音

写清环境声的强弱、呼吸是否可闻、台词音色和语速。声音必须服从表演：抢话可覆盖尾音，克制落泪通常不需要持续抽泣，环境声不盖过关键对白。

### 5. 负面约束

从以下类别中选择本场真正需要的约束：

- 主体：对手抢镜、清晰正脸、错误单人特写。
- 表演：突然变脸、提前落泪、持续怒吼、夸张皱眉、频繁摇头、朗诵腔。
- 动作：无预备动作的扑抱、拍桌无反馈、肢体穿插、方向跳变。
- 镜头：越轴、无动机推拉、切镜破坏反应拍、焦点漂移。
- 连续性：道具复原、泪痕消失、站位互换、台词和口型错位。
- 画面：塑料皮肤、过度磨皮、无关字幕、水印、Logo。

不要把全部类别复制进每条提示词。

## 三、条件模块

### 单人微表情

触发源可以在画外，但必须说明人物先感知什么。常用轨迹是“视线变化 → 呼吸或口颌变化 → 肩颈/重心变化 → 行动或静止余韵”。眼泪不是默认高潮，也可以以稳定直视、松开手掌或停止说话结束。

### 台词表演

为每句关键台词绑定：

```text
准备动作 → 开口音色 → 关键词动作 → 句中停顿/对方抢入 → 说完后的反应
```

若只有一句短台词，也要保留开口前和结束后的时间。避免角色说完立刻切镜或动作归零。

### 双人对手戏

按因果轮次编排：

```text
A 的动作或台词
→ B 被击中的即时反应
→ B 回避、抢话、沉默或反击
→ A 因 B 的变化重新调整
→ 下一轮冲突或关系转折
```

反应拍可以短至约 0.2–0.5 秒，但仅是剪辑节奏提示，不保证模型逐帧执行。J-cut/L-cut 只用于确有切镜的对白覆盖；连续单镜头不需要这些术语。

### 强动作与环境反馈

强动作写物理因果链。例如拍桌：

```text
手掌接触桌面 → 杯体震动 → 液面与冰块响应 → 衣料/桌面声音 → 周围人物短暂抬眼后恢复
```

环境反应低于主角强度，不让旁人围观或夺走注意力。

## 四、可选表演信号

以下是候选动作，不是固定配方：

| 情绪阶段 | 可选可见信号 |
|---|---|
| 察觉异常 | 身体短暂停住、呼吸停半拍、视线由发散转为聚焦 |
| 强装轻松 | 浅笑不稳定、眼神停留偏久、说话前轻微吸气 |
| 委屈上涌 | 目光下落再返回、下唇绷住、肩膀轻微收拢 |
| 忍住眼泪 | 泪膜形成但不落、鼻翼微动、下颌短暂用力、吞咽 |
| 做出决定 | 视线稳定、眨眼减少、面部变化暂时停止、重心站稳 |
| 愤怒露出脆弱 | 音量高点后下降、呼吸紊乱、手掌松开、目光回避 |

先判断角色和情境，再选择信号；不要机械复制整行。

## 五、交付前检查

- 抽象情绪是否都至少有一个可见或可听的表现？
- 每个阶段是否由上一阶段触发，而不是状态跳跃？
- 眼神是否写清方向、速度或停留，而非只有“悲伤地看”？
- 台词是否有前置动作和说后余韵？
- 双人戏是否存在明确的 A→B 触发关系？
- 镜头、声音、环境是否服务主体而非堆术语？
- 负面约束是否针对本场高概率失败？
- 最后一条连续性总约束是否与时间轴一致？
