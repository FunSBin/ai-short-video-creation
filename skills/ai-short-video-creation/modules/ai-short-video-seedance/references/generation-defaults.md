# 项目视频参数与执行权限

这是公开安装包的配置说明，不代表任何安装者已经授权收费任务。先读取项目设置与当前用户明确要求；没有配置时说明建议，必要信息影响结果时提问，不虚构历史偏好。

| 参数 | 选择依据 |
| --- | --- |
| 平台／模型 | 用户指定和实际可用入口；Seedance系列是本模块适配方向，不保证特定版本当前可用 |
| 画幅 | 本次发布和镜头用途；16:9可作为横向叙事的建议，用户指定竖屏时按其要求 |
| 质量／模式 | 用户预算和平台支持；样片与正式成片分开，不自动升级、超分或购买 |
| 时长 | 按对白、动作、反应和切镜动态预算，再核验当前入口合法范围；不固定每条秒数 |
| 参考绑定 | 核对本次模型的真实语法、图片／音频数量和容量，不沿用别的平台索引 |
| 生成权限 | 项目默认`manual`；只配置提示和画布、查询已有结果不等于提交媒体生成 |

用户已明确选择过的有效配置复用，当前新要求优先。若用户自行点视频生成按钮，助手始终只配置和回读，不触发提交。明确授权媒体执行后也只做该范围，不自动增加重试、换更贵模型、转成片或发布。

历史案例中的Seedance 2.5 Draft、16:9、480P和CLI枚举只是当时入口的例子，当前支持度须实际核验。文中其他文件提到的默认参数均服从本说明与当前项目配置；不把安装技能视为参数确认或执行授权。
