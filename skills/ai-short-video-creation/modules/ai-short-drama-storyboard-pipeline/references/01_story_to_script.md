# Story Outline To Script

Use this module when turning an outline, mythology material, or episode idea into a complete short-drama script.

## Inputs To Gather

- Series title, deity or protagonist, episode count, target duration.
- Current outline and any user edits.
- Required myth or folklore facts.
- Key scenes already planned.
- Visual continuity needs such as age stages, costume changes, locations, props, or divine forms.

## Script Rules

- Preserve known tradition and public myth. If inventing connective tissue, mark it as dramatization and keep it compatible with the tradition.
- Use modern short-drama dialogue: emotionally clear, not overly classical, but not slangy.
- Keep motivation clear before spectacle. A miracle or divine act must answer a character conflict.
- Every episode should contain:
  - opening hook
  - conflict setup
  - emotional reversal
  - iconic mythic image
  - episode-end hook or closure
- Record stage transitions: prince, ascetic, divine warrior, deified form, later worship context, and so on.

## Dialogue Check

- If the line will later be generated with lip-sync, keep each visible spoken line short enough for its planned seconds.
- If a line is long but important, split it across shots or mark part as off-screen audio.
- Do not compress a line so much that the scene loses logic.
