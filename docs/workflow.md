# 从创意到发布的实际流程

1. **接手／立项**：读取已有材料和项目规则，确认真实停点；没有剧本时立项、人物与世界规则、分集和剧本。已有作品从对应阶段继续。
2. **资产**：先列依赖，再制作或复用人物、场景、道具与特效。维护唯一原件和当前版本。人物设定、场景几何、关键帧分别承担不同职责。
3. **分镜**：锁世界位置、机位方向、地标、动作因果和人物反应。按当前平台合法时长规划生成段，不机械分秒。
4. **提示词**：每次提交有完整首帧状态、引用职责、变化过程、切镜、声音与尾态；不要求模型记住上一段。
5. **生成／手动执行**：按实际工具和授权处理。默认只配置和交付材料；用户手动执行后提供媒体或让可用工具读取真实结果。查询或下载失败不重新生成。
6. **样片复核**：依据实际秒段判断位置、表演、动作、道具和特效，音轨实听后才判断声音；用户通过的部分锁定，失败段最小修复。
7. **剪辑交回**：选可用版本与入出点、校声音和字幕，使用可用工具导出。没有执行工具则交剪辑表，不把计划称成片。
8. **封面与文案**：继承风格、突出本次核心事件；对外编号独立记录，标题承诺在正片可兑现。发布账号操作另需授权。

各阶段入口与状态写进项目唯一入口，文件和原件位置保持可追踪。新增版本同步实际引用；历史失败媒体保留证据。所有阶段都区分设计、生成、自检、平台配置和用户通过。

## 工具要求

| 能力 | 没有该能力时 |
| --- | --- |
| 文件读写 | 只能在对话交付文字，须明确没有保存文件 |
| 看图／生图 | 列图像提示与上传清单，已有图不能声称目检通过 |
| 视频生成 | 手动在所选平台执行，回传真实结果 |
| 抽帧／播放与音频试听 | 分别标明能确认的范围，不能以截图证明完整动态或声音 |
| 剪辑／编码 | 交剪辑表与目标规格，不能称已导出 |

可使用宿主已有的可用工具、用户自己的平台或手动工作流；安装本包不会自动安装、登录或购买任何服务。
